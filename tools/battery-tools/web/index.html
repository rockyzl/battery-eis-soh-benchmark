    02 / IMPEDANCE ANALYSIS
    Equivalent-circuit fitting and linear-KK assessment
    Inspect measured Nyquist curves and a model-dependent fit. Three reference spectra include linear-KK checks and RC-versus-CPE fits computed with impedance.py.
    Candidate: R0 + parallel(R1, CPE) + semi-infinite Warburg. Only capacitive points enter this fit. Fitted parameters do not uniquely identify a physical process.

    KK consistency does not prove linearity, stationarity or a degradation mechanism. More than one circuit may explain a spectrum.
    

    03 / BRING YOUR DATA
    Battery-test CSV import and dQ/dV analysis
    Files stay in this browser session. This version reads the CSV schemas below; vendor-native files need a verified adapter.
    EIS CSV
    One row per frequency point. Use actual imaginary impedance, not −Im(Z), in z_imag_ohm. Single-spectrum fitting is available here. Multi-cell prediction for imported data is a later adapter.
    cell_id,cycle,frequency_hz,z_real_ohm,z_imag_ohm
cell_A,1,1000,0.41,-0.03
    The example is a derivative of the cited Cambridge data.
    Cycling CSV and dQ/dV
    One continuous constant-current charge or discharge segment per cell/cycle/direction. Capacity must accumulate through the segment.
    cell_id,cycle,voltage_v,capacity_mah,current_a
cell_A,1,3.6,0.02,0.01
    Checks current variation and voltage reversals before local-linear differentiation over 20 mV. Peaks depend on sampling and preprocessing. No diffusion or EIS estimate comes from a smooth cycling curve.
    

    04 / THE EXISTING TOOL ECOSYSTEM
    Battery data-processing and calculation tools
    The difficult work is deciding what data and assumptions each calculation needs, then checking whether its result answers the research question.
    The agent's research job
    Identify data and units, assess method applicability, develop and test analysis code, compare models on independent cases, and propose a discriminating measurement.
    Implemented: public-data audit, impedance.py reference checks and fits, browser circuit fitting, CSV/dQ/dV checks, grouped model selection and prediction. Other packages below are researched integration candidates.
